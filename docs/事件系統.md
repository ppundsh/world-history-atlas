# 事件系統

事件系統用現有的地圖和時間軸，逐步呈現一個事件的發展過程，例如：

- 烏俄戰爭的勢力變化
- 兩伊戰爭的邊界
- 十日戰爭
- 八國聯軍
- 十字軍東征
- 一、二次大戰的戰線

**目前未開啟。** 網址加上 `?events` 才會出現，例如 `https://…/CountryHistory/?events#y=1900`。開啟後「顯示」選單裡會多一個「Event」下拉選單。範例事件是「八國聯軍（1900–1901）」。

## 主類別

類別定義在 `data-pipeline/events/categories.json`，包含四語名稱與代表色。新增類別就改這個檔。

| 代碼 | 類別 |
|---|---|
| `war` | 戰爭 |
| `expedition` | 遠征與干涉 |
| `revolution` | 革命與內戰 |
| `independence` | 獨立與分裂 |
| `treaty` | 條約與領土交換 |
| `migration` | 遷徙與移民 |
| `disaster` | 災害 |

## 檔案格式

每個事件是一個檔案：`data-pipeline/events/<id>.json`。從 `_template.json` 複製開始，完整範例見 `eight-nation-alliance-1900.json`。

事件本身的欄位：

| 欄位 | 說明 |
|---|---|
| `id` | 與檔名相同，小寫加連字號，結尾加年份 |
| `category` | 上表的代碼之一 |
| `title`、`summary` | 四語中的 `zh-Hant`、`en`、`ja`。簡體由 OpenCC 自動轉換 |
| `start`、`end` | 日期，可寫 `YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`；西元前用負號 |
| `view` | 開啟時地圖的中心與縮放 `{lon, lat, k}` |
| `sides` | 交戰或參與各方：`id`、四語 `name`、`color`（`#rrggbb`） |
| `sources` | 來源清單 `{title, url}`，**必填** |
| `keyframes` | 依日期排列的關鍵影格 |

每個關鍵影格的欄位：

| 欄位 | 說明 |
|---|---|
| `date` | 日期，必須在 `start`–`end` 之間，且按順序排列 |
| `caption` | 這一步發生什麼（四語） |
| `src` | 這一步依據哪些來源（`sources` 的索引），**至少一個** |
| `areas` | 控制區：`{side, polygon}`，polygon 是 GeoJSON 多邊形座標（經度在前） |
| `fronts` | 戰線：`{line}`，紅色虛線 |
| `arrows` | 進軍方向：`{side, line}`，箭頭畫在最後一點 |
| `markers` | 地點：`{kind, lon, lat, name}`；kind 為 `battle`、`siege`、`capture`、`treaty`、`city` 或 `note` |

座標一律是 `[經度, 緯度]`。

## 新增事件的標準流程

1. **建檔**：複製 `_template.json`，改名為 `<id>.json`。
2. **資料蒐集**：
   - 先列出來源，填進 `sources`。
   - 戰線與控制區要有地圖或文字來源，例如戰史地圖、ISW 每日戰況圖、維基百科戰役條目的地圖。
   - 每個影格都要標出 `src`。
3. **描點**：
   - 在 [geojson.io](https://geojson.io) 畫多邊形或線，複製座標貼進 `areas`、`fronts`、`arrows`。
   - 地點座標可從維基百科條目的座標取得。
4. **驗證**：執行 `node data-pipeline/events/build.mjs --check`。它會檢查：
   - 必填欄位與四語是否齊全
   - 類別是否存在
   - 日期格式與順序
   - 來源索引
   - 座標範圍
   - 陣營代碼

   有任何錯誤就列出並以狀態 1 結束。`build-all.sh` 每次建置都會執行，錯誤會擋下建置。
5. **預覽**：
   1. 執行 `node data-pipeline/events/build.mjs`（輸出到 `public/data/events/`）。
   2. 執行 `npm run dev`，開 `http://localhost:5173/?events`。
   3. 在「顯示 → Event」選擇事件，用 ◀ ▶ 逐格檢查。
6. **提交**：一個事件一次提交，訊息寫「事件名稱＋影格數＋主要來源」。

## 程式結構

| 檔案 | 作用 |
|---|---|
| `data-pipeline/events/build.mjs` | 驗證＋編譯，輸出 `index.json` 與每個事件的 JSON |
| `src/eventlayer.js` | 載入事件，把目前影格畫在平面地圖上（控制區、戰線、箭頭、地點） |
| `src/main.js` 的 `setupEvents()` | 選單、播放面板。切換影格時把時間軸跳到該年，底下的國界照常顯示當年狀態 |

## 正式開啟前要做的事

- 事件疊加層目前只畫在平面地圖上，地球模式還要加上 MapLibre 圖層。
- 影格之間目前是直接切換，可加入戰線與控制區的形狀內插動畫。
- 時間軸要改成在事件期間以日為單位，並在時間軸上標示影格。
- 「顯示」選單的「Event」標籤要翻譯，並把開關改成正式選項。
