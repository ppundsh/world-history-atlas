# 歷史疆域查核方案

這份文件說明怎麼查核每個國家、地區的歷史演變，以及怎麼確保每項修正都有出處。查核分三層：

1. **自動檢查**：每次建置時用程式掃過全部年份，找出可疑的地方。
2. **有出處的修正表**：只在這裡改資料，每一行都要附來源連結。
3. **人工複核流程**：按優先順序逐筆處理，並留下紀錄。

## 1. 資料來源與信任順序

| 順序 | 來源 | 用在哪裡 |
|---|---|---|
| 1 | 本專案 `data-pipeline/overrides/*.tsv` 中附來源的修正 | 覆蓋下面所有來源 |
| 2 | Natural Earth（現代國界，1946 年後的主權國家形狀） | 世界模式的現代形狀、台灣與中國模式的底圖 |
| 3 | 內政部鄉鎮界（taiwan-atlas 套件）、各區域模式的 `admin.tsv` | 台灣模式的行政區 |
| 4 | Cliopatria（Seshat 全球歷史疆域資料，CC BY） | 世界模式的歷史形狀 |
| 5 | Wikidata（QID） | 用來確認同一個政權，例如 Cliopatria 與 Natural Earth 的配對 |

國名與政權的認定是**實際控制**優先：地圖畫的是誰實際統治，名稱用該政權自己對外的正式稱呼。例如「大和」「日本」，而不是「倭」。

## 2. 自動檢查（`data-pipeline/qa.py`）

`build-all.sh` 在產生世界資料後會自動執行 `qa.py`。它在 61,533 個陸地取樣點（0.5° 格網）上逐年檢查，報告寫在 `data-pipeline/qa_report.md`。

| 檢查 | 意義 | 嚴格模式 |
|---|---|---|
| 閃爍空白 | 前後一年都有政權，當年卻沒有 | 失敗 |
| 1500 年後新出現的空白 | 某地從有政權變成空白 | 失敗 |
| 1946 年後主權重疊 | 兩個主權國家佔同一塊地，例如 1971 年以色列被併入埃及的那種錯誤 | 只列出（爭議地區屬正常） |
| 政權中斷 | 同一政權消失 20 年內又出現 | 只列出 |

執行方式有兩種：

- 單獨執行：`python3 data-pipeline/qa.py <NE目錄>`
- 讓嚴格項目擋下建置：`QA_STRICT=1 bash data-pipeline/build-all.sh`

目前還有待複核的舊項目，所以預設建置不開嚴格模式。清完後應改成預設開啟。

`build.py` 本身已經會自動處理兩類問題：

- **Wikidata 配對**：Cliopatria 與現代國家先用 Wikidata QID 配對，避免「重疊最多就當成同一國」的錯誤。這就是 1971 年以色列消失的原因。
- **自動補洞**：
  - 1500 年後，兩年以內的閃爍空白，如果前後是同一政權就補上。
  - 1946 年後，前一年的政權延續到有新資料為止。

每次建置會印出補了幾處。

## 3. 有出處的修正表

所有手動修正只放在 `data-pipeline/overrides/`。每一行最後一欄都是來源網址，沒有來源的修正不收。

| 檔案 | 用途 | 例子 |
|---|---|---|
| `names.tsv` | 政權名稱（四語）、可按年份切段 | 明 → 大明帝國；540–700 大和、701 起日本 |
| `geometry.tsv` | 形狀修正：`set`／`add`／`subtract` 一個時段的疆域 | 1950 年 5 月起海南島歸中華人民共和國；1950 年起中華民國 = 台澎金馬 |
| `holes.tsv` | 補上原始資料漏掉的政權 | 1865–1876 哲德沙爾（阿古柏政權） |
| `extra_states.tsv` | 原始資料沒有的國家 | |
| `religion*.tsv` | 各政權主要宗教與宗教介紹 | |
| `../taiwan/*.tsv`、`../china/*.tsv` | 區域模式的逐月控制與行政區 | 1950 年 10 月台灣調整為 16 縣 |

形狀可以用以下方式指定：

- `NE:<ISO3>`：Natural Earth 國家
- `NE1:<一級行政區名>`：Natural Earth 省級區
- `TW:<單位>`：台灣鄉鎮組成的單位

## 4. 人工複核流程

1. **排序**：從 `qa_report.md` 取項目，依下列優先順序處理：
   1. 1946 年後的錯誤
   2. 1500 年後的大片空白與閃爍
   3. 名稱錯誤
   4. 其餘

   `names_review.tsv` 是自動產生的名稱待審清單。
2. **查證**：每筆至少一個可連結來源。優先使用學術著作、官方文件，其次是維基百科條目並引用其腳註。日期要細到月份；若只知道年份，在備註中說明。
3. **修正**：寫進對應的修正表，附上來源網址。不要改原始資料或程式裡的特殊判斷。
4. **驗證**：
   1. 重新建置。
   2. 確認 `qa_report.md` 該項消失，而且沒有新增項目。
   3. 在網站上用 `#y=<年>` 開到該年檢查。
5. **紀錄**：提交訊息寫「年份＋地區＋來源」，例如 `1950 Hainan → PRC (Battle of Hainan Island)`。

使用者回報的錯誤也走同一流程。查證後如果是原始資料的問題，順便整理成清單回報給 Cliopatria 專案。

## 5. 目前狀態（本版建置）

- 閃爍空白 11 筆、1500 年後新空白 100 筆（1946 年後 0 筆）、1946 年後主權重疊 63 個年份（17 組，多為國界碎片或爭議地區；報告列出每一組）、政權中斷 220 筆。
- 建置會自動執行「1946 年後現代國家優先」：現代國家實際畫出的領土，不能同時屬於另一個政權（本版移除 423 處，例如法國蓋住阿爾及利亞、英國蓋住阿曼）。Cliopatria 的錯誤 Wikidata 編號在 `overrides/qid.tsv` 修正。
- 1946 年後的重疊多數是爭議地區，例如喀什米爾、西撒哈拉，依爭議區觀點顯示，屬於預期內。其餘項目列在報告中待逐筆複核。
- 已修正並附來源的項目：
  - 1971 年以色列（Wikidata 配對）
  - 海南島 1950 年
  - 中華民國在台灣改為實際控制
  - 1864–1876 新疆（東干起事、哲德沙爾）
  - 「倭」改「大和／日本」
  - 中國歷代王朝正式國號
