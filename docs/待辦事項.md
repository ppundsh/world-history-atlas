## 功能
- [x] 各地區模式的行軍、戰線與遷徙箭頭（約 110 條，可開關）
- [x] 事件時間軸即時篩選；隱藏模式入口改為篩選輸入 fgo + Enter
- [x] 「標記」選單分組（通用／本模式），依模式隱藏
- [x] 世界模式首都（Wikidata）與首都出現時的城市照片
- [x] 語言模式「多層語言變遷」快速聚焦選單
- [x] 隱藏模式：英靈列傳（131 位，依原型人物；只用 Commons 肖像）
- [ ] 英靈列傳：補齊其餘英靈（原創或無明確地點者另行處理）
- [x] 語言的發展模式（語系分布、遷徙箭頭、台灣南島語與閩語細節）
- [ ] 語言的發展：分布以橢圓概略標示，日後可改用實際語言分布多邊形（如 Glottolog、WLMS）
- [x] 錄影／截圖（含背景音樂）
- [x] 首都顯示改為頂端開關
- [x] 點國家後鎖定在畫面中
- [x] 藝術史代表作品縮圖、館藏與文獻連結
- [x] 縮圖大小、建築風格、文化代表人物
- [x] 事件時間軸開關、事件說明與圖片（維基百科）、播放時浮現事件圖片
- [x] 投影介紹的向量縮圖；錄影可選是否含音樂；恢復正軸保留「上方」設定
- [x] 事件地點（圓點、縮圖、淡出；開關）；各地區模式加入各自重視的事件與座標；台灣械鬥開關恢復
- [x] 世界大事與各地區所有事件補上座標
- [x] 金融史模式；模式選單分為世界與地區；語言會消失與被取代；多層語言變遷案例
- [x] 播放到底不自動暫停；點事件不改變播放狀態；手機直向地圖按鈕橫排、橫向直排
- [x] 統治範圍＋行政區劃同時開啟時的雜點（單元幾何改以 mapshaper snap/clean 修正）
- [ ] 藝術史：補齊尚無作品的流派（諾克、吳門畫派、狩野派、上海畫派、哈林文藝復興、台展、具體派、五月畫會、極簡主義、帕普尼亞、八五新潮）
- [ ] 變形提示遮罩：目前停用，需重新設計各投影的計算方式與顯示
- [ ] 越南：939–1469 年與 1954–1975 年的行政區劃細分
